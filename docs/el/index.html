Φλεγόμενη Περγαμηνή

Από το ξύπνημα ως την ώρα του ύπνου, δείτε τη μέρα σας να καίγεται.

Σχετικά με την εφαρμογή

Τι είναι η Φλεγόμενη Περγαμηνή;

Η Φλεγόμενη Περγαμηνή είναι μια εφαρμογή αντίστροφης μέτρησης που δείχνει πόσο απομένει από τη μέρα σας ως ένα φύλλο περγαμηνής που καίγεται αργά. Από το ξύπνημα ως την ώρα του ύπνου βλέπετε με μια ματιά πόσος χρόνος απομένει, ώστε να αξιοποιήσετε τις ώρες που σας μένουν.

Ημερήσια αντίστροφη μέτρηση Εβδομάδα / μήνας / έτος Widget αρχικής οθόνης Dynamic Island Widget οθόνης κλειδώματος

Πώς να τη χρησιμοποιήσετε

Ορίστε την ώρα ξυπνήματος και ύπνου

Πατήστε το κουμπί ⚙️ πάνω δεξιά για να ορίσετε την ώρα ξυπνήματος και την ώρα ύπνου. Η περγαμηνή αρχίζει να καίγεται όταν ξυπνάτε και η αντίστροφη μέτρηση τελειώνει την ώρα του ύπνου.

Επιλέξτε χρονικό διάστημα

Επιλέξτε 1 ημέρα · 1 εβδομάδα · 1 μήνας · 1 έτος από τις καρτέλες στην κορυφή και η περγαμηνή καίγεται για να δείξει πόσο απομένει από το διάστημα.

Widget αρχικής οθόνης

Πατήστε παρατεταμένα την αρχική οθόνη → Προσθήκη widget → αναζητήστε Φλεγόμενη Περγαμηνή για να προσθέσετε widget ημέρας, εβδομάδας, μήνα ή έτους. Διατίθενται μικρό, μεσαίο και μεγάλο μέγεθος.

Dynamic Island και οθόνη κλειδώματος

Μόλις ξεκινήσει η αντίστροφη μέτρηση, μπορείτε να παρακολουθείτε τον χρόνο που απομένει ζωντανά στο Dynamic Island και στην οθόνη κλειδώματος. Τραβήξτε προς τα κάτω το Dynamic Island για περισσότερες λεπτομέρειες, μαζί με το animation της περγαμηνής που καίγεται.

Συχνές ερωτήσεις

Το widget δείχνει διαφορετική ώρα από την εφαρμογή

Λόγω του τρόπου λειτουργίας του iOS, τα widget της αρχικής οθόνης δεν μπορούν να ενημερώνονται σε πραγματικό χρόνο. Όταν ανοίγετε την εφαρμογή, τα δεδομένα του widget συγχρονίζονται αυτόματα. Για ζωντανή αντίστροφη μέτρηση, χρησιμοποιήστε το Dynamic Island και την οθόνη κλειδώματος.

Τι εμφανίζεται όσο κοιμάμαι;

Μετά την ώρα του ύπνου εμφανίζεται ένα animation με μια φλεγόμενη καρδιά που δείχνει πόσο έχει προχωρήσει ο ύπνος σας ως το ξύπνημα. Ένα φρέσκο φύλλο περγαμηνής ετοιμάζεται 30 λεπτά πριν ξυπνήσετε.

Πότε φτάνουν οι ειδοποιήσεις;

Λαμβάνετε μια ειδοποίηση μία ώρα πριν την ώρα του ύπνου. Αν δεν φτάσει, ελέγξτε ότι επιτρέπονται οι ειδοποιήσεις στις Ρυθμίσεις → Ειδοποιήσεις → Φλεγόμενη Περγαμηνή.

Αδειάζει η εφαρμογή την μπαταρία μου;

Η αντίστροφη μέτρηση μέσα στην εφαρμογή προχωρά μία φορά το δευτερόλεπτο, ενώ τα widget ακολουθούν ένα χρονοδιάγραμμα χαμηλής κατανάλωσης που διαχειρίζεται το σύστημα, οπότε η επίδραση στη διάρκεια της μπαταρίας είναι ελάχιστη.

Απόρρητο

Πώς χειριζόμαστε τα στοιχεία σας

Η ώρα ξυπνήματος, η ώρα ύπνου, οι προθεσμίες, οι απολογισμοί και τα τεφροδοχεία σας αποθηκεύονται μόνο στη συσκευή σας. Ο προγραμματιστής λαμβάνει μόνο ανώνυμα στατιστικά χρήσης, διαγνωστικά κατάρρευσης και τα σχόλια που επιλέγετε να στείλετε.

  • Η εφαρμογή και τα widget της μοιράζονται δεδομένα μόνο μέσω ενός App Group στη συσκευή σας.
  • Χωρίς διαφημίσεις, χωρίς παρακολούθηση.
