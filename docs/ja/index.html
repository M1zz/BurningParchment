燃える羊皮紙

起きてから眠るまで、1日が燃えていく様子を見届けましょう。

アプリについて

どんなアプリですか？

燃える羊皮紙は、1日の残り時間を羊皮紙が少しずつ燃えていく姿で表すカウントダウンアプリです。起床時刻から就寝時刻まで、あとどれくらい時間が残っているかがひと目でわかるので、1日をより大切に過ごせます。

1日のカウントダウン 週 / 月 / 年 ホーム画面ウィジェット Dynamic Island ロック画面ウィジェット

使い方

起床時刻と就寝時刻を設定する

右上の ⚙️ ボタンをタップして、起床時刻と就寝時刻を設定してください。起床時刻になると羊皮紙が燃えはじめ、就寝時刻になるとカウントダウンが終わります。

期間を選ぶ

上部のタブで 1日・1週間・1か月・1年 から期間を選ぶと、その期間の残り時間を羊皮紙の燃え具合で表示します。

ホーム画面ウィジェット

ホーム画面を長押し → ウィジェットを追加 → 燃える羊皮紙 を検索すると、日・週・月・年のウィジェットを追加できます。小・中・大の3サイズに対応しています。

Dynamic Island とロック画面

カウントダウンが始まると、Dynamic Island とロック画面で残り時間をリアルタイムに確認できます。Dynamic Island を下に引くと、羊皮紙が燃えるアニメーションとともに詳しい情報が表示されます。

よくある質問

ウィジェットとアプリで時間の表示が違います

iOS の仕組み上、ホーム画面ウィジェットはリアルタイムに更新できません。アプリを開くとウィジェットのデータが自動で同期されます。リアルタイムのカウントダウンは Dynamic Island とロック画面でご確認ください。

寝ているあいだは何が表示されますか？

就寝時刻を過ぎると燃えるハートのアニメーションが表示され、起床時刻までの睡眠の進み具合がわかります。起床の30分前には、新しい羊皮紙が用意されます。

通知はいつ届きますか？

就寝時刻の1時間前に通知が届きます。届かない場合は、設定 → 通知 → 燃える羊皮紙 で通知が許可されているかご確認ください。

バッテリーをたくさん消費しますか？

アプリ内のカウントダウンは1秒ごとに更新されますが、ウィジェットはシステムが管理する省電力のタイムライン方式で動くため、バッテリーへの影響は最小限に抑えています。
