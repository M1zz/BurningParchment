개인정보 처리방침

최종 업데이트: 2026년 8월 18일

요약

불타는 내인생은 신원 정보를 수집하지 않습니다

앱에서 만든 기록(취침·기상 시간, 데드라인, 회고, 항아리)은 전부 사용자의 기기 안에만 남습니다. 개발자에게 전달되는 것은 아래에 적은 익명 통계, 크래시 진단, 그리고 사용자가 직접 보낸 피드백뿐입니다.

🔒 회고 내용은 기기 밖으로 나가지 않음 · 광고·추적 없음

기기에만 저장되는 정보

앱이 만든 기록

아래 항목은 사용자의 기기 내부(UserDefaults)에만 저장됩니다.

  • 기상 시간 · 취침 시간
  • 데드라인
  • 회고와 항아리

이 값들은 앱과 위젯 간 데이터 공유를 위해 기기 내 App Group 저장소를 통해서만 사용되며, 앱을 삭제하면 함께 삭제됩니다.

개발자에게 전달되는 정보

익명 사용 통계

앱 개선을 위해 아래 항목이 개발자의 iCloud(CloudKit) 저장소로 전송됩니다.

  • 무작위로 생성한 설치 식별자(UUID)
  • 앱 버전, 플랫폼과 OS 버전, 언어 설정
  • 실행 횟수, 사용 일수, 주요 기능 사용 이벤트 이름

설치 식별자는 기기 식별자(IDFA·IDFV)나 Apple 계정과 무관하며, 앱을 지웠다 다시 설치하면 새로 만들어집니다.

크래시·응답 지연 진단

앱이 비정상 종료되거나 멈췄을 때 iOS(MetricKit)가 만든 진단 정보 — 발생 유형, 스택 트레이스, 앱/OS 버전, 기기 종류가 전송됩니다. 회고 등 앱에 입력한 내용은 포함되지 않습니다.

직접 보낸 피드백

설정 화면에서 문의를 보낼 때만 전송됩니다. 작성한 내용과 기기·앱 버전 정보가 함께 전달되며, 답장을 원해 직접 입력한 경우에 한해 이름과 이메일 주소가 포함됩니다.

수집하지 않는 정보

아래 항목은 수집하지 않습니다

  • 회고·데드라인 등 앱에 입력한 내용 (피드백에 직접 적어 보낸 경우 제외)
  • 이름, 이메일, 전화번호 등 신원 정보 (피드백에 직접 입력한 경우 제외)
  • 위치 정보
  • 연락처, 사진, 건강 데이터
  • 기기 식별자 (IDFA, IDFV 등)
  • 광고 관련 데이터

제3자 공유

데이터를 공유하지 않습니다

앱은 어떠한 광고 네트워크나 제3자 분석 SDK도 사용하지 않습니다. 위에 적은 통계·진단·피드백은 개발자 본인의 iCloud 저장소로만 전송되며, 다른 회사의 데이터와 결합하거나 광고 목적으로 추적하지 않습니다.

알림

로컬 알림만 사용합니다

취침 1시간 전 알림은 기기 내에서 예약되는 로컬 알림으로, 외부 서버를 거치지 않습니다. 알림 권한은 사용자가 언제든지 iOS 설정에서 변경할 수 있습니다.

아동 개인정보 보호

만 14세 미만 아동

본 앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

방침 변경

변경 시 이 페이지를 통해 안내합니다

개인정보 처리방침이 변경될 경우 이 페이지의 최종 업데이트 날짜를 수정하고 내용을 업데이트합니다. 중요한 변경이 있을 경우 앱 업데이트 노트를 통해 별도로 안내할 수 있습니다.
