กระดาษหนังลุกไหม้

ตั้งแต่ตื่นจนถึงเวลานอน ดูวันของคุณไหม้ไปทีละนิด

เกี่ยวกับแอป

กระดาษหนังลุกไหม้คืออะไร

กระดาษหนังลุกไหม้เป็นแอปนับถอยหลังที่แสดงว่าวันของคุณเหลืออีกเท่าไรด้วยแผ่นกระดาษหนังที่ค่อย ๆ ไหม้ ตั้งแต่ตื่นจนถึงเวลานอน คุณเห็นได้ในพริบตาว่าเหลือเวลาเท่าไร เพื่อใช้ชั่วโมงที่เหลือให้คุ้มที่สุด

นับถอยหลังรายวัน สัปดาห์ / เดือน / ปี วิดเจ็ตหน้าจอโฮม Dynamic Island วิดเจ็ตหน้าจอล็อก

วิธีใช้

ตั้งเวลาตื่นและเวลานอน

แตะปุ่ม ⚙️ ที่มุมขวาบนเพื่อตั้งเวลาตื่นและเวลานอน กระดาษหนังจะเริ่มไหม้เมื่อคุณตื่น และการนับถอยหลังจะสิ้นสุดตอนเวลานอน

เลือกช่วงเวลา

เลือก 1 วัน · 1 สัปดาห์ · 1 เดือน · 1 ปี จากแท็บด้านบน แล้วกระดาษหนังจะไหม้เพื่อแสดงว่าช่วงเวลานั้นเหลืออีกเท่าไร

วิดเจ็ตหน้าจอโฮม

แตะหน้าจอโฮมค้างไว้ → เพิ่มวิดเจ็ต → ค้นหา กระดาษหนังลุกไหม้ เพื่อเพิ่มวิดเจ็ตรายวัน รายสัปดาห์ รายเดือน หรือรายปี มีขนาดเล็ก กลาง และใหญ่ให้เลือก

Dynamic Island และหน้าจอล็อก

เมื่อเริ่มนับถอยหลังแล้ว คุณติดตามเวลาที่เหลือแบบสดได้ใน Dynamic Island และบนหน้าจอล็อก ลาก Dynamic Island ลงเพื่อดูรายละเอียดเพิ่มเติมพร้อมแอนิเมชันกระดาษหนังที่กำลังไหม้

คำถามที่พบบ่อย

วิดเจ็ตแสดงเวลาไม่ตรงกับในแอป

เนื่องจากข้อจำกัดของ iOS วิดเจ็ตบนหน้าจอโฮมจึงอัปเดตแบบเรียลไทม์ไม่ได้ เมื่อเปิดแอป ข้อมูลของวิดเจ็ตจะซิงก์โดยอัตโนมัติ หากต้องการนับถอยหลังแบบสด ให้ใช้ Dynamic Island และหน้าจอล็อก

ระหว่างที่ฉันหลับจะแสดงอะไร

หลังเวลานอน จะมีแอนิเมชันหัวใจที่กำลังลุกไหม้ แสดงว่าการนอนของคุณผ่านไปถึงไหนแล้วจนถึงเวลาตื่น กระดาษหนังแผ่นใหม่จะเตรียมพร้อมก่อนคุณตื่น 30 นาที

การแจ้งเตือนมาตอนไหน

คุณจะได้รับการแจ้งเตือนหนึ่งชั่วโมงก่อนเวลานอน หากไม่ได้รับ ให้ตรวจสอบว่าอนุญาตการแจ้งเตือนไว้ที่ การตั้งค่า → การแจ้งเตือน → กระดาษหนังลุกไหม้

แอปกินแบตเตอรี่ไหม

การนับถอยหลังในแอปเดินทุกวินาที แต่วิดเจ็ตทำงานตามตารางเวลาประหยัดพลังงานที่ระบบจัดการ ผลต่ออายุแบตเตอรี่จึงน้อยที่สุด

ความเป็นส่วนตัว

เราจัดการข้อมูลของคุณอย่างไร

เวลาตื่น เวลานอน กำหนดส่ง บันทึกทบทวน และโถของคุณถูกเก็บไว้ในอุปกรณ์ของคุณเท่านั้น ผู้พัฒนาจะได้รับเพียงสถิติการใช้งานแบบไม่ระบุตัวตน ข้อมูลวินิจฉัยการแครช และความคิดเห็นที่คุณเลือกส่งมาเท่านั้น

  • แอปและวิดเจ็ตแชร์ข้อมูลกันผ่าน App Group บนอุปกรณ์ของคุณเท่านั้น
  • ไม่มีโฆษณา ไม่มีการติดตาม
